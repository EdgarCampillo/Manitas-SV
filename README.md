                DESCRIPCION: 
                
Manitas SV es una plataforma salvadoreña inclusiva que 
combina videos interactivos, ejercicios prácticos y
reconocimiento de señas en tiempo real mediante visión artificial.
No solo enseñamos LESSA, sino que
promovemos un aprendizaje gamificado y accesible para
personas sordas, mudas o con diferentes niveles de
comunicación. Además, facilitamos la participación de familiares,
docentes y público general, construyendo
una comunidad que aprende y crece unida.
